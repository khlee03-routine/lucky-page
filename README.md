# 행운의 페이지 · 책읽는 방주

책읽는 방주 이벤트용 행운권 추첨 웹페이지입니다. 01~99 번호를 펼친 책 모양 슬롯으로 한 자리씩 공개합니다.

- 사용: https://khlee03-routine.github.io/lucky-page/
- 오프라인: 이 폴더를 통째로 내려받아 `index.html`을 브라우저로 열면 됩니다.

## 사용법

- **추첨** (또는 Space): 앞자리 공개
- **뒷자리 공개** (또는 Space): 뒷자리 공개
- **당첨 확정 / 재추첨**: 재추첨된 번호와 당첨 번호는 다시 나오지 않습니다.
- 오른쪽 위 흐린 ☰ 버튼 (또는 L): 당첨·재추첨 명단, 제목, 효과음, 회전 시간, 전체 초기화

기록은 브라우저 저장소에만 남으며, 사이트 데이터(캐시)를 지우면 초기화됩니다.

## 구성

- `index.html`: 페이지 전체 (HTML/CSS/JS)
- `logo.png`: 책읽는 방주 로고
- `sounds/`: 효과음 파일 (없으면 내장 합성음 사용, `sounds/README.txt` 참고)
- `fonts/`: 나눔스퀘어라운드 (SIL Open Font License)
